# Trip Planner App

## Description

Trip Planner App is a React application for planning trips.

The application allows users to:

- Create new trips
- Delete trips
- Add activities to each trip
- Delete activities
- Filter activities by category, status and reservation
- Sort activities by date, cost or status
- View the total budget for each trip
- Save the data in Local Storage

## Technologies

- React
- JavaScript
- CSS
- Local Storage
